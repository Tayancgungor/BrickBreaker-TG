# Brick Breaker

A brick-breaking arcade game prototype developed in
Unity using C#.

## Overview

Brick Breaker is a completed game development course
project that I expanded with personal modifications
to gameplay mechanics, scripts, and visual presentation.

The project provided practical experience with Unity,
C# scripting, game interactions, and creating a
playable prototype.

## Features

- Classic brick-breaking gameplay
- Player-controlled paddle
- Ball and brick interactions
- Customized gameplay behavior
- Modified visual assets and environments
- Customized user interface

## My Contributions

- Customized gameplay mechanics and C# scripts
- Modified player interactions
- Redesigned visual assets and materials
- Customized environments and UI elements
- Tested gameplay behavior during development
